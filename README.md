Simplified Data Encryption Standard (S-DES)
A Python implementation of the Simplified Data Encryption Standard (S-DES) algorithm developed as part of a college cryptography assignment.

📖 Overview
Simplified DES (S-DES) is a teaching-oriented version of the Data Encryption Standard (DES). It is designed to demonstrate the fundamental concepts of symmetric-key encryption, including key generation, permutations, substitutions, and Feistel rounds.

This project implements the complete S-DES encryption and decryption workflow in Python for educational purposes.

✨ Features
Generate subkeys (K1 and K2)

Encrypt plaintext using the S-DES algorithm

Implements:

Initial Permutation (IP)
Inverse Initial Permutation (IP⁻¹)
Expansion/Permutation (EP)
S-Boxes (S0 & S1)
P4 Permutation
Left Circular Shifts
XOR Operations
Feistel Structure
🛠️ Tech Stack
Python
🚀 How to Run
Clone the repository
git clone <repository-url>
Navigate to the project directory
cd SDES
Run the program
python main.py
